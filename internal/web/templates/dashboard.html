Getting started

  1. Download your preferred Vintage Story build in Versions.
  2. Use Make a Server to configure identity, world generation and survival rules.
  3. Install server-side mods from the ModDB browser.
  4. Schedule snapshots under Temporal Rollbacks and watch your world through the live console.

Temporal stability checklist

  • Both TCP and UDP must be forwarded on the instance port (from 1.20 onward).
  • Clients must run the same game version as the server.
  • World configuration is applied only when the world is first generated.
  • Backups before updates are strongly recommended when mods add blocks.
