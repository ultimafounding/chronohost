ChronoHost — Technical Specification SheetProject Name: ChronoHostDomain: Vintage Story Dedicated Server ManagementTarget Environment: Docker / Docker Compose (Linux & Windows Host)Version: 0.2.0-draft1. Executive SummaryChronoHost is a containerized dedicated server management utility and web portal designed specifically for Vintage Story. Inspired by the game's temporal mechanics, ChronoHost focuses on temporal stability (uptime and crash recovery), world preservation (automated, intelligent backups), seamless mod ecosystem management, and a 1:1 visual Server Creation Portal that exposes every world generation parameter available in the game client.2. Core ObjectivesContainer-First Deployment: Run ChronoHost and its managed Vintage Story server instances cleanly via Docker and Docker Compose with persistent volumes for worlds, mods, and backups.1:1 In-Game World Creation Portal: Provide a rich web wizard that mirrors the Vintage Story client's "Customize World" screen, generating valid WorldConfiguration blocks inside serverconfig.json before initial world generation.Temporal Stability (Reliability): Ensure high server availability through process supervision, graceful shutdowns, and automated crash recovery.Mod & World Integrity: Simplify ModDB dependency tracking, version pinning, and incremental world backups.3. Fetch available builds directly from the official Vintage Story CDN/API with side-by-side binary caching.Crash Watchdog: Detect unexpected process exits, log crash dumps, and auto-restart with configurable backoff timers.4.4 Mod Manager (ModDB Integration)Direct ModDB Sync: Search, download, and update mods directly via the official Vintage Story ModDB API (mods.vintagestory.at/api).Compatibility Guard: Warn administrators if an installed mod targets a different game version than the active server binary.4.5 Backups & "Temporal Rollbacks"Automated Snapshots: Trigger full or incremental backups of the .vcdbs save file and serverconfig.json on a schedule or prior to server updates.Retention Policies: Configurable Grandfather-Father-Son (GFS) rotation.One-Click Restore: Safely halt the server, swap the save file with a selected snapshot, and reboot.4.6 Live Console, Telemetry & AlertsInteractive Stdin Stream: Real-time log streaming via WebSockets with ANSI color support and command execution.World Telemetry: Track online players, in-game date/season, temporal storm status, and container CPU/RAM usage.Discord Webhooks: Push alerts for server start/stop, crashes, player joins/leaves, and backup completions.5.
